# STARsolo CellRanger2.2
{: .no_toc }

STARsolo's default filter. Named after Cell Ranger 2.2, it takes the same robust maximum (the
99th percentile of the top 3,000 barcodes) and keeps every barcode within a factor of 10 of it, but
computes it once on the data instead of averaging 100 bootstraps, and takes the 31st-largest
total where Cell Ranger takes the 30th.

## At a glance

| | |
|---|---|
| Id | `starsolo-cellranger2.2` |
| Tool | STAR 2.7.3a and later (`--soloCellFilter CellRanger2.2 3000 0.99 10`) |
| Category | rank-threshold |
| Counts | UMIs of the detected barcodes |
| Needs expected cells | uses 3,000 unless told otherwise |
| Deterministic | yes |
| Original licence | MIT |
| Validated against | `STAR --runMode soloCellFiltering` 2.7.10a and 2.7.11b on public 10x matrices (exact) |

## How it works

With \(N\) expected cells, percentile \(q\) and ratio \(r\) (defaults 3000, 0.99, 10), and the
detected barcodes' totals sorted in decreasing order \(u_{(0)} \ge u_{(1)} \ge \dots\):

1. \(i = \operatorname{round}(N (1 - q))\), which is 30 for the defaults (0-based, so the 31st
   largest).
2. The robust maximum is \(m = u_{(\min(nCB - 1,\, i))}\).
3. The cut is \(c = \max(1, \operatorname{round}(m / r))\).
4. Every detected barcode with total \(\ge c\) is a cell.

## Versions

| STAR | Variant | `--tool-version` | Behaviour |
|---|---|---|---|
| 2.7.0a – 2.7.2d | — | — | no cell filter in STAR |
| 2.7.3a – 2.7.4a | `v1` | `2.7.3a` | rounding as `(int)(x + 0.5)`; no floor, so a cut of 0 keeps every detected barcode |
| 2.7.5a – 2.7.7a | `v2` | `2.7.5a` | as v1, cut floored at 1 |
| 2.7.8a – 2.7.11b | `v3` | `2.7.8a` | as v2, rounding with C `round()`; the three numbers become optional |

`(int)(x + 0.5)` and `round(x)` agree for every non-negative input except a few values within one
ulp of a half, so v2 and v3 give the same cells in practice.

## Parameters

| Option | Default | Original | Meaning |
|---|---|---|---|
| `--expected-cells` | 3000 | `nExpectedCells` | expected number of cells |
| `--max-percentile` | 0.99 | `maxPercentile` | percentile of the top expected cells taken as the robust maximum |
| `--max-min-ratio` | 10 | `maxMinRatio` | the robust maximum is divided by this |

## Run it

```bash
sc-droplets call starsolo-cellranger2.2 Solo.out --barcodes cells.tsv
sc-droplets call starsolo-cellranger2.2 raw_feature_bc_matrix.h5 --tool-version 2.7.4a --expected-cells 5000
```

```python
import sc_droplets as scd

adata = scd.read("Solo.out")
scd.call(adata, "starsolo-cellranger2.2")
```

## Differences from the original

None known. STAR counts every feature of a loaded matrix; this method does too (it does not
restrict itself to Gene Expression).

## Validation

`tests/test_validation_starsolo.py` compares the cells with those `STAR --runMode
soloCellFiltering` keeps (STAR 2.7.10a and 2.7.11b, static Linux binaries) on two public 10x raw
matrices; they are identical. The oracle is generated by `oracles/starsolo/run.sh`. The 2.7.3a –
2.7.7a variants differ only in the lines quoted above, read from those releases' source; they
have no `soloCellFiltering` mode to run.
